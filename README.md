Sistema "Patinhas com segurança".
Objetivo: Servir como serviço de organização de clientes e animais em um pet shop.

RF01: O sistema deve permitir o cadastro de clientes;
RF02: O sistema deve listar clientes cadastrados;
RF03: O sistema deve permitir editar clientes;
RF04: O sistema deve permitir excluir clientes;
RF05: O sistema deve permitir visualizar dados de um cliente;
RF06: O sistema deve permitir cadastrar animais;
RF07: O sistema deve listar animais cadastrados;
RF08: O sistema deve permitir editar animais;
RF09: O sistema deve permitir excluir animais;
RF10: O sistema deve exibir o dono do animal.

RN01: Todo animal deve ser associado a um cliente;
RN02: Clientes podem possuír vários animais;
